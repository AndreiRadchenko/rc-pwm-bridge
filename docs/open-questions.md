# Відкриті питання

Питання не блокують створення промптів. Вони блокують лише відповідний подальший дизайн, реалізацію або прийняття. Відповіді записувати в decisions та специфікацію етапу, не приховувати за defaults.

| ID | Що визначити | Коли закрити |
|---|---|---|
| Q01 | E01 закрито для зафіксованого macOS arm64 environment: SDK commit/submodules, tools та Python wheelhouse/хеші перевірені; чистий offline replay і перевірка SDK залежностей пройшли. Докази — `specs/01-foundation/verification/build.md`, pins — `tools/environment/environment.lock.json`. Тимчасові локальні шляхи перед використанням перевіряються повторно. | Закрито для зазначеного environment; clean target build і фізичне прийняття — окремі перевірки 01 |
| Q02 | Контактний дизайн визначено: D17 підтвердив C3 rev v0.4, 4 MB і native USB; D18 прийняв pinout та живлення 3V3/GND, D19/D20 визначили RC=GPIO3, PWM=GPIO0 та перемичку DIR–GND на MD20A без GPIO1 для [профілю](../hardware/esp32-c3-supermini-profile.md). Окрема схема/continuity більше не блокує програмну підготовку. Залишаються зовнішній bias, реальні напруги/якість живлення та startup waveform; одночасне USB VBUS + external 3V3 не прийняте як перевірений режим. Приймач може продовжувати видавати валідні імпульси після втрати радіоканалу. Міст не може визначити цю втрату лише зі свіжості PWM; потрібне налаштування й окрема перевірка failsafe приймача.
