# 04-pump-output — PWM із DIR–GND без насоса

Стан: заплановано, не розпочато. Залежності: 01-foundation,02-control-core,03-rc-capture. Вимоги: R01,R04,R06,R08,R12.

## Перед роботою

Підготувати ізольовану перевірку без насоса. Виміряти сигнали, полярність, boot/reset/upload, перевірити вплив кнопок MD20A. Зберегти осцилограми та обмеження.

Відкриті питання: Q02,Q04,Q06; Q05 must not be bypassed. Перевірити прийняття залежностей за фактичними результатами, а не наявністю файлів.

## Порядок

1. У Codex викликати `$speckit-specify` з вмістом [specify.md](specify.md).
2. Прочитати специфікацію; закрити питання, що блокують цей етап, за потреби через `$speckit-clarify`.
3. Окремо викликати `$speckit-plan` з вмістом [plan.md](plan.md).
4. Перевірити план і відповідність конституції. Tasks та Implement виконуються лише окремими запитами.

Для скриптів установлювати `SPECIFY_FEATURE_DIRECTORY=specs/04-pump-output`. Вихідні файли належать цьому каталогу, незалежно від поточної Git-гілки.

## Критерій завершення

Виміряні 1000 Гц, проміжні duty, сталі LOW/HIGH і постійна перемичка DIR–GND (без GPIO DIR); насос не використовується для цього прийняття.

Результат майбутньої реалізації записати в `specs/04-pump-output/verification/`: що перевірено програмно, що зібрано, що перевірено фізично, за яких умов і що лишилося pending. Створення промптів, spec чи plan не завершує етап.
