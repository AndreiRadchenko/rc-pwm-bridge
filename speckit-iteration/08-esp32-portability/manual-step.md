# 08-esp32-portability — Інший ESP32

Стан: відкладений етап, не активований. Залежності: 07-ignition-channel. Вимоги: R02,R03,R08,R12,R14.

## Перед роботою

Етап відкладений. Обрати конкретну плату, отримати її документацію, повторити перевірку живлення, GPIO, таймінгів і стартових станів.

Відкриті питання: Q08; platform-specific Q02,Q03,Q06. Перевірити прийняття залежностей за фактичними результатами, а не наявністю файлів.

## Порядок

1. У Codex викликати `$speckit-specify` з вмістом [specify.md](specify.md).
2. Прочитати специфікацію; закрити питання, що блокують цей етап, за потреби через `$speckit-clarify`.
3. Окремо викликати `$speckit-plan` з вмістом [plan.md](plan.md).
4. Перевірити план і відповідність конституції. Tasks та Implement виконуються лише окремими запитами.

Для скриптів установлювати `SPECIFY_FEATURE_DIRECTORY=specs/08-esp32-portability`. Вихідні файли належать цьому каталогу, незалежно від поточної Git-гілки.

## Критерій завершення

Конкретна друга ESP32-плата має відтворювану збірку й окремі докази прийняття; C3 працює без регресії.

Результат майбутньої реалізації записати в `specs/08-esp32-portability/verification/`: що перевірено програмно, що зібрано, що перевірено фізично, за яких умов і що лишилося pending. Створення промптів, spec чи plan не завершує етап.
