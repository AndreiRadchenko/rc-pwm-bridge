# 02-control-core — Переносиме ядро керування

Стан: заплановано, не розпочато. Залежності: 01-foundation. Вимоги: R03,R04,R05,R12.

## Перед роботою

Узгодити Q04: допуски ширини, округлення, фільтрацію й реакцію на invalid. Не затверджувати 100 мс або повторне ввімкнення за замовчуванням.

Відкриті питання: Q04; Q05 remains unresolved until 05. Перевірити прийняття залежностей за фактичними результатами, а не наявністю файлів.

## Порядок

1. У Codex викликати `$speckit-specify` з вмістом [specify.md](specify.md).
2. Прочитати специфікацію; закрити питання, що блокують цей етап, за потреби через `$speckit-clarify`.
3. Окремо викликати `$speckit-plan` з вмістом [plan.md](plan.md).
4. Перевірити план і відповідність конституції. Tasks та Implement виконуються лише окремими запитами.

Для скриптів установлювати `SPECIFY_FEATURE_DIRECTORY=specs/02-control-core`. Вихідні файли належать цьому каталогу, незалежно від поточної Git-гілки.

## Критерій завершення

Ядро тестується без MCU, карта й валідація визначені; немає прихованої автокалібровки чи апаратних залежностей.

Результат майбутньої реалізації записати в `specs/02-control-core/verification/`: що перевірено програмно, що зібрано, що перевірено фізично, за яких умов і що лишилося pending. Створення промптів, spec чи plan не завершує етап.
