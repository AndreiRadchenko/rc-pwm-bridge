# 09-arduino-nano — Порт Arduino Nano

Стан: відкладений етап, не активований. Залежності: 08-esp32-portability. Вимоги: R03,R08,R12,R15.

## Перед роботою

Прочитати спільний [контекст промптів](../current-baseline.md) і вказані в ньому чинні джерела. Документи 01–03 містять програмні результати й відкриті фізичні перевірки; наявність реалізації не означає прийняття обладнання.

Етап відкладений. Визначити модель Nano та логічні рівні, перевірити таймерний план і апаратний fail-off. Не переносити 5-вольтову схему на ESP32 без узгодження рівнів.

Відкриті питання: Q09; окремі апаратні залежності Q02/Q03/Q06 для обраної Nano. Перевірити залежності за фактичними результатами, окремо програмні й фізичні gates.

Зберегти strict C++11 ядро та прийняту поведінку 01–08. Nano має окремі build/toolchain і адаптери; GPIO, RMT/LEDC та FreeRTOS-рішення C3 не переносяться автоматично. Native ESP-IDF для ESP32 зберігається.

## Порядок

1. У Codex викликати `$speckit-specify` з вмістом [specify.md](specify.md).
2. Прочитати специфікацію; закрити питання, що блокують цей етап, за потреби через `$speckit-clarify`.
3. Окремо викликати `$speckit-plan` з вмістом [plan.md](plan.md).
4. Перевірити план і відповідність конституції. Tasks та Implement виконуються лише окремими запитами.

Під час Specify створити або перемкнути відповідну feature-гілку за `AGENTS.md`/D10 зі збереженням роботи користувача. D10 тепер формально закріплено як Specify-only правило принципуV конституціїv2.0.0/D74; commit/push та апаратні дії він не дозволяє. Інші фази самі гілку не перемикають.

Для скриптів установлювати `SPECIFY_FEATURE_DIRECTORY=specs/09-arduino-nano`. Вихідні файли належать цьому каталогу, незалежно від поточної Git-гілки.

## Критерій завершення

Точна Nano має окрему збірку, адаптери, ресурсний бюджет і фізичні докази відповідності; ESP32 не регресував.

Результат майбутньої реалізації записати в `specs/09-arduino-nano/verification/`: що перевірено програмно, що зібрано, що перевірено фізично, за яких умов і що лишилося pending. Створення промптів, spec чи plan не завершує етап.
